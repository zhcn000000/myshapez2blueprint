

# Shapez 2 Blueprint Collection
## Usage
Click the green "Code" button to Download ZIP, extract it, and place the contents into the blueprint folder.
### Blueprint Folder Location
_In-game, open the blueprint interface, select and click "Open Folder"<br>
or paste `%USERPROFILE%\Appdata\LocalLow\tobspr Games\shapez 2\blueprints` into the file explorer address bar<br>
which corresponds to `C:\Users\Username\AppData\LocalLow\tobspr Games\shapez 2\blueprints`_
## Current Grid Sizes
All single-layer machines and signal-related components occupy a single 1x1 cell.\n
Multi-layer machines: 1x1 four-way: Recycler, Shape Spawner (Sandbox only), Liquid Spawner (Sandbox only)<br>
1x1 two-way: Splitter, Clockwise Rotation, Counter-clockwise Rotation, 180° Rotation<br>
1x1: Color Picker (extreme compression), Single-output Color Mixer (input belt not full, output belt full), Filter, Reader, Cutter (center-symmetrical only)<br>
2-cell: Stacker (1x1 version incomplete), Cutter, Color Mixer, Swap (structure by @DarkAngelEX, extreme compression)<br>
3-cell: Crystal Spawner<br>
